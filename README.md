# Pop Dash

Open `index.html` directly in your browser by double-clicking it, or use your browser’s **Open File** command and select it. Keep `index.html`, `style.css`, and `game.js` in the same folder.

Click **Let’s play**, then click or tap the moving ball to earn one point per catch. Each round lasts 30 seconds. **Restart** starts a fresh round at any time.

The game uses only HTML, CSS, and JavaScript. It works offline and requires no installation, backend, database, or API keys.
